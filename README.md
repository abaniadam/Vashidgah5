# وشیدگاه — تقویم هجری شمسی (اندروید)

پروژه‌ی اندروید که صفحه‌ی `app/src/main/assets/index.html` را در یک WebView نمایش می‌دهد.

## ساخت APK با GitHub
1. یک مخزن (Repository) جدید در GitHub بسازید.
2. همه‌ی فایل‌های داخل این پوشه (از جمله پوشه‌ی `.github`) را در ریشه‌ی مخزن آپلود کنید.
3. به تب **Actions** بروید. ساخت به‌صورت خودکار شروع می‌شود (یا **Build Android APK ← Run workflow**).
4. پس از پایان، از پایین صفحه‌ی همان اجرا، فایل **Vashidgah-APK** را دانلود کنید. داخل آن `app-debug.apk` است.
5. فایل را روی گوشی نصب کنید (نصب از منابع ناشناس باید مجاز باشد).

## اعلان یادآوری‌ها
- یادآوری‌هایی که تیک «اعلان یک روز قبل» دارند، ساعت ۹ صبحِ یک روز قبل به‌صورت اعلان اندروید نمایش داده می‌شوند.
- بار اول (اندروید ۱۳ به بعد) برنامه اجازه‌ی نمایش اعلان را می‌پرسد؛ آن را تأیید کنید.
- اعلان‌ها برای ۳۶۶ روز آینده زمان‌بندی می‌شوند، با هر بار باز کردن برنامه یا ذخیره‌ی یادآوری به‌روز می‌شوند و بعد از ریستارت گوشی دوباره برقرار می‌شوند.
- اگر گوشی برنامه را به‌دلیل بهینه‌سازی باتری محدود کند، اعلان ممکن است با تأخیر برسد.

## تغییر تقویم
فقط فایل `app/src/main/assets/index.html` را عوض کنید و دوباره commit کنید؛ APK جدید ساخته می‌شود.

## نکته‌ها
- نام و شناسه‌ی برنامه: `com.vashidgah.calendar`
- فایل ساخته‌شده «debug» است و با کلید آزمایشی امضا شده؛ برای نصب شخصی کافی است. برای انتشار در مارکت‌ها باید نسخه‌ی release با کلید خودتان امضا شود.
- فونت وزیرمتن از اینترنت بارگذاری می‌شود؛ بدون اینترنت از فونت گوشی استفاده می‌شود.
